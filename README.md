# ابزارهای ریاضی آنلاین (math-tools.ir)

مجموعه‌ای از ابزارهای رایگان ریاضی به فارسی، بدون نیاز به نصب و بدون سرور؛ فقط HTML، CSS و جاوااسکریپت که روی GitHub Pages اجرا می‌شود.

## ابزارها

| ابزار | آدرس |
|---|---|
| ماشین‌حساب دنباله‌ای | `/sequence-calculator/` |
| تجزیه عدد به عوامل اول | `/prime-factorization/` |
| ماشین‌حساب | `/calculator/` |
| محاسبه کسرها | `/fractions/` |
| ب.م.م و ک.م.م | `/gcd-lcm/` |
| تشخیص عدد اول | `/prime-checker/` |
| غربال اراتستن | `/sieve-of-eratosthenes/` |
| محاسبه درصد | `/percentage/` |
| میانگین | `/average/` |
| حل معادله درجه اول | `/linear-equation/` |
| حل معادله درجه دوم | `/quadratic-equation/` |
| تبدیل مبنای اعداد | `/number-base-converter/` |

## ساختار پروژه

```
index.html              صفحهٔ اصلی
<tool>/index.html       یک صفحهٔ جدا برای هر ابزار (برای سئو)
assets/style.css        استایل پایه
assets/pages.css        استایل بخش توضیحی زیر ابزارها
assets/theme.css        تم و طراحی ظاهری (روشن و تیره)
assets/app-*.js         منطق ابزارها، تاریخچه، علاقه‌مندی‌ها و زبان
assets/extra-tools.js   معادلهٔ درجه دوم و تبدیل مبنا
assets/routes.js        تبدیل جابه‌جایی بین ابزارها به آدرس‌های واقعی
assets/fonts/           فونت وزیرمتن (woff2 سبک‌شده)
sitemap.xml, robots.txt, 404.html
```

## اجرا روی کامپیوتر

صفحه‌ها آدرس‌هایی مثل `/assets/style.css` دارند، پس باید با یک سرور محلی باز شوند:

```
python -m http.server 8000
```

بعد `http://localhost:8000` را باز کن.

## ویژگی‌ها

- هر ابزار آدرس، عنوان و توضیح مخصوص خودش را دارد.
- حالت روشن و تیره، نسخهٔ انگلیسی، تاریخچهٔ محاسبات و علاقه‌مندی‌ها.
- همهٔ محاسبه‌ها در مرورگر انجام می‌شود و داده‌ای به جایی ارسال نمی‌شود.
